Project Overview
Nilex (نايلكس) هي منصة إعلانات مبوبة مصرية تعمل باللغتين العربية والإنجليزية، تتيح للمستخدمين نشر وتصفح الإعلانات في مختلف الفئات (سيارات، عقارات، إلكترونيات، ملابس، وغيرها) مع نظام نقاط واقتصاد رقمي متكامل.

الهدف من المشروع

  • منصة بيع وشراء محلية على غرار OLX/Dubizzle مخصصة للسوق المصري
  • دعم كامل للعربية (RTL) مع إمكانية التبديل للإنجليزية
  • نظام تحقق بالـ OTP لضمان جودة المستخدمين
  • نظام نقاط لتحفيز النشاط وتمييز الإعلانات
  • لوحة إدارة متكاملة للإشراف على المحتوى
  • تكامل مع الذكاء الاصطناعي (Gemini) لإنشاء الإعلانات تلقائيًا

app/Auth/ — Multi-layer Security

خطوات تسجيل مستخدم جديد

1. يملأ النموذج (إيميل أو هاتف مصري 01XXXXXXXXX) → 2. فحص حد الأجهزة (max 3 حسابات/جهاز) → 3. إنشاء الحساب + منح 100 نقطة ترحيبية → 4. إرسال OTP (إيميل في Queue email-high أو SMS في Queue sms-high) → 5. التحقق من OTP → 6. فحص ref= في الـ Session ومنح نقاط الإحالة

بصمة الجهاز (Device Fingerprint)

  • SHA-256 hash من: User Agent + IP + Custom Headers + Cookie UUID
  • أقصى 3 حسابات لكل جهاز/IP/بصمة
  • Cookie device_id صالح لمدة ~5 سنوات

PointService — نظام النقاط

  • عمليات Credit (إضافة) وDebit (خصم) وTransfer (نقل)
  • يستخدم lockForUpdate() لمنع Race Conditions
  • يحفظ morph reference على كل معاملة
  • مُسجَّل كـ Singleton في AppServiceProvider

PaymobService — المدفوعات

  • يحصل على Auth Token من Paymob API
  • ينشئ Order بالـ Amount المطلوب (جنيه مصري)
  • يُرجع Payment Key لفتح Iframe
  • الخطط المتاحة: 100 نقطة / 500 نقطة / 1000 نقطة

SmsService — الرسائل النصية

  • يرسل OTP عبر SMS API المكوّن في .env
  • في بيئة التطوير يُسجّل الرسالة في الـ Logs بدلًا من الإرسال الفعلي
  • يستخدم: SMS_USERNAME, SMS_PASSWORD, SMS_SENDER_NAME
